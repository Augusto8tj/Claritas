1. VISÃO GERAL E FILOSOFIA
--------------------------------------------------------------------------------
O Quant Radar (V2 - Novo) é um terminal de trading quantitativo de nível profissional 
projetado para mercados de volatilidade de alta frequência. Sua filosofia central é 
a "Seletividade de Instrumento baseada em Regime". Ao contrário de robôs padrão, 
ele não apenas prevê a direção; ele seleciona o instrumento financeiro específico 
(Accumulators, Multipliers ou Options) que oferece a maior vantagem estatística 
para a microestrutura atual do mercado.

2. TECNOLOGIAS E STACK CORE
--------------------------------------------------------------------------------
- Framework: Next.js 15 (App Router) + React 19.
- Estilização: Tailwind CSS + Shadcn UI (Temas Customizados: Ocean, Forest, Desert).
- Dados em Tempo Real: Deriv API (WebSocket) via AppID Institucional.
- Inteligência Local: Integração com Ollama Studio (CIO - Chief Investment Officer).
- Motor Matemático: Implementação customizada de HMM (Hidden Markov Models), 
  Geometric Brownian Motion (GBM) e Inferência Bayesiana.
- Backend: Firebase Firestore (Persistência) & Auth.

3. INOVAÇÕES CHAVE (O "QUANT ADVANTAGE")
--------------------------------------------------------------------------------
A. EXECUÇÃO POLIMÓRFICA MULTI-INSTRUMENTO:
O autopilot não é mais binário (Sobe/Desce). Ele pode executar:
- ACCUMULATORS: Ativados durante regimes 'Ranging' (lateral) com baixa volatilidade.
- MULTIPLIERS: Ativados durante regimes 'Breakout' ou 'Strong Trending'.
- CALL/PUT OPTIONS: Ativados para momentum direcional padrão.

B. RADAR DE OPORTUNIDADES ESTOCÁSTICAS:
Um scanner de segundo plano que cicla pelos 5 principais índices sintéticos 
(1HZ10V a 1HZ100V). Ele executa inferências assíncronas para cada ativo, marcando-os 
como "Qualificados" quando o LLM local detecta uma anomalia de alta confiança.

C. INTELIGÊNCIA ZEN QUALITATIVA:
O painel de "Inteligência Meditativa". Usa o LLM para gerar insights qualitativos 
(ZenThoughts) para equilibrar o psicológico do operador, traduzindo dados brutos 
em perspectivas filosóficas de mercado.

4. INTEGRAÇÃO DE SISTEMAS E FLUXO DE DADOS
--------------------------------------------------------------------------------
- HOOK [use-deriv-api-v2.tsx]: O "Coração". Gerencia o handshake seguro, 
  autorização síncrona e roteamento de ordens polimórficas.
- HOOK [use-ai-quant-terminal-v2.tsx]: O "Cérebro". Orquestra o ciclo de análise. 
  Injeta um snapshot de 30 velas + histórico de 15 decisões no Ollama para 
  gerar o próximo movimento estratégico.
- SERVICE [advanced-trading-services.ts]: O "Calculador". Fornece features de 
  microestrutura como Velocidade de Ticks, Desequilíbrio de Volume e Volatilidade 
  Yang-Zhang.

5. OBJETIVOS ARQUITETURAIS
--------------------------------------------------------------------------------
- CONSCIÊNCIA DE REGIME: Silenciar o "ruído" combinando estratégias com estados de mercado.
- DILUIÇÃO DE RISCO: Uso do Critério de Kelly Fracionado (0.25) para prevenir ruína.
- COMPENSAÇÃO DE LATÊNCIA: Medição do delay "Tick-to-Result" para ajustar 
  horizontes preditivos.
- AUDITORIA COGNITIVA: Cada decisão da IA é logada (Reasoning Log) para análise 
  forense da lógica do LLM.

6. ENGENHARIA DE PROMPT PARA O CIO (OLLAMA)
--------------------------------------------------------------------------------
O sistema usa um prompt JSON-Strict altamente estruturado que força o LLM a 
agir como um Analista Quant Sênior. Ele exige:
- 'action' (Viés direcional)
- 'recommendedContract' (Escolha do instrumento)
- 'confidence' (Percentual 0-100)
- 'reasoning' (Justificativa técnica)
- 'zenThought' (Insight qualitativo)
